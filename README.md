# 🎓 Online Education Guru (OEG)

બાલવાટિકાથી ધોરણ 8 સુધીના વિદ્યાર્થીઓ, શિક્ષકો અને આચાર્યો માટેનું **પ્રીમિયમ શૈક્ષણિક પ્લેટફોર્મ** —
**GitHub Pages** પર હોસ્ટ થાય છે અને **Blogger (blogspot.com)** માં live embed થાય છે.

> **ભાષાઓ:** ગુજરાતી • हिन्दी • English (એક ક્લિકમાં બદલાય) | **ડાર્ક મોડ** | **PWA-ready**

## 🚀 ડિપ્લોય: GitHub Pages

1. આ રિપો GitHub પર push કરો (branch: `main`).
2. **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `(root)`.
3. સાઈટ live: `https://onlineeducationguru.github.io/OEG/`
4. `js/config.js` અને `data/site-config.json` માં `siteUrl` તમારા Pages URL મુજબ રાખો.

> ⚠️ **નોંધ:** `node_modules/` GitHub પર push **ન કરો** — `.gitignore` માં છે. ફોન્ટ્સ પહેલેથી `assets/fonts/` માં કોપી થયેલા છે.

## 🅱️ Blogger માં લગાવવું (XML Theme)

> ✅ **iframe વાપરવો પડતો નથી.** `blogger/OEG-Blogger-Native.xml` લગાવો એટલે આખી સાઈટ
> (હોમ · પાઠ્યપુસ્તક · સ્વાધ્યાયપોથી · વિડિયો · ક્વિઝ · રમત · બ્લોગ · Admin) **બ્લોગર ના પાનાં પર જ** ચાલે —
> browser ના address bar માં ફક્ત તમારું `…blogspot.com` (અને custom domain) સરનામું દેખાય, બીજું ક્યાંય નહીં.

**એક વખત લગાવવું:**
1. Blogger Dashboard → **Theme** → **Customize ▼** → **Backup** (હાલની થીમ સાચવો — જરૂરી!).
2. **Theme → Customize ▼ → Restore → Upload** → `blogger/OEG-Blogger-Native.xml` પસંદ કરો.
3. **Setting → Permissions → Bloggers → +Add authors** માં તમારું email રાખો (એ જ email થી Admin login થશે).
4. થઈમ માં ૪ `<b:section>` છે ⇒ **Blogger → Layout** માં હવે Header / Sidebar / Footer જગ્યા માં **Add a Gadget** ચાલે
   (Label, Link List, HTML/JavaScript, AdSense gadget વગેરે — એ સાઈટ ની ડિઝાઇન પ્રમાણે સજાય).
5. જુઓ → બ્લોગર પર આખી સાઈટ ચાલે. CSS/JS/JSON ફાઈલો jsDelivr CDN પરથી આવે છે
   (`https://cdn.jsdelivr.net/gh/OnlineEducationGuru/OEG@main/`), એટલે **નવો XML ફરી upload કરવાની જરૂર નથી** —
   GitHub માં push કરો (અથવા Admin Panel માં save કરો) ⇒ બ્લોગર ની સાઈટ પણ થોડી મિનિટ માં નવી દેખાશે.

**થીમ નવો બનાવવો** (જયારે `index.html` નું markup બદલાય, જેમ કે નવું મેનુ પાનું):
```bash
node scripts/blogger.mjs          # → blogger/OEG-Blogger-Native.xml (auto: index.html + js/** → CDN)
node scripts/blogger.mjs --ref <sha>    # કોઈ fix pin કરવો હોય તો (CDN કૅશ ન બદલાય)
node scripts/blogger.mjs --pages-links # SEO પાનાં (g/ p/ q/) GitHub Pages પર જ મોકલવા હોય તો
```
> 📌 ડિફૉલ્ટ માં ધોરણ/ક્વિઝ ની લિંક બ્લોગર નાં route જ વાપરે (`#/grade/5`, `#/quiz`) એટલે વાંચનાર બ્લોગર પર રહે.

**પુરાણો iframe થીમ** (`blogger/OEG-Blogger-Theme.xml`) — એ પણ હવે upload થઈ જાય (જૂનાં ૪ દોષ સુધાર્યા છે),
પણ SEO/UX દૃષ્ટિએ native થીમ જ સારો: iframe માં GitHub Pages ની સાઈટ નીચે બંધાયેલી રહે છે
અને browser ના address bar માં `github.io` સરનામું પણ દેખાય છે.

**જો મેનુ/સાઈડબાર ખાલી દેખાય (જૂના થીમ માં એવું બન્યું હતું):** આ વર્ઝન માં સાઈટ પોતે જ એ જગ્યા બનાવી લે છે
(કોઈ div બ્લોગર કાઢી નાખે તો પણ મેનુ ફરી ભરાય), ઉપર નું બ્લોગર bar છુપાવે છે, અને ફોન્ટ ની CSS પણ CDN થી લોડ કરે છે.
એટલે **નવો XML ફરી એક વાર upload કરો** (Theme → Restore) — એ જ ઉકેલ છે.

- 🖼 **▶ વિડિયો પ્લેલિસ્ટ / ચૅનલ લિંક** પણ કામ કરે: `youtube.com/playlist?list=…`, `watch?v=…&list=…` કે `…/channel/UC…` ਨાં લિંક ਨાંખો ⇒ એ જ સિરીઝ સાઈટ પર ચાલે, અને "🔁 આગલો વિડિયો" કાર્ડ + વિડિયો પૂરો થાય એટલે આગલો આપોઆપ ચાલે.

## 🛠️ Admin Panel વાપરવું

> 🔒 **એક્સેસ:** Admin Panel **ફક્ત એક જ email+પાસવર્ડથી** ખુલે છે, જે `data/admin.json` માં **email = base64** + **પાસવર્ડ = SHA-256 hash** સ્વરૂપે સુરક્ષિત સેવ છે (કોઈ પણ ભાષક ફાઈલ વાંચે તો email/પાસવર્ડ સીધા દેખાતા નથી).

0. **વિદ્યાર્થી/શિક્ષક રજિસ્ટ્રેશન:** `#/register` — નામ+ઈમેઈલ+પાસવર્ડ+ભૂમિકા ભરો ⇒ **તરત login** (Admin ની મંજૂરી નહીં).
   ખાતું એ ઉપકરણ ના localStorage માં (salt + SHA-256 hash થઈ ને) રહે છે; પછી તે જ ઉપકરણ એ જ email+પાસવર્ડ થી login કરી શકે.
1. **Admin ખોલવું:** 🛠️ **Admin Panel લિંક મેનુ માં છુપાયેલી છે** — એ ફક્ત unlock થયા પછિ જ દેખાય.
   પહેલી વાર URL માં `#/admin` લખો (અથવા બ્લોગર/પેજ પર `…/#/admin`) → login → પછી મેનુ માં લિંક આપોઆપ આવે.
2. **પ્રથમ વખત (setup):** email + તમારો નવો પાસવર્ડ + **એકવાર સિક્રેટ કોડ** ભરો → **દાખલ થાઓ**.
   - 🔑 **સિક્રેટ કોડ = GitHub Fine-grained PAT** — login card પર ક્યાંય "GitHub/PAT/token" લખ્યું દેખાતું નથી; સમજ **લોગિન પછી** Panel → 🔗 Connect માં "❓ સિક્રેટ કોડ ક્યાંથી મેળવવો?" પર મળશે (README માં પણ છે).
   - પગલાં: https://github.com/settings/personal-access-tokens → **Generate new token → Fine-grained** → name `OEG`, 90 days → **Only select repositories** = `OnlineEducationGuru/OEG` → **Contents: Read and write** → Generate → copy.
3. **બીજી વારથી:** ફક્ત email + પાસવર્ડ. (કોઈ auto-fill નહીં — નીચે જુઓ.) સિક્રેટ કોડ પહેલી વાર ભરેલો હોય તો આપોઆપ લાગુ થાય — વારંવાર copy-paste કરવાનો પ્રશ્ન જ નથી (જુઓ: 📱 નીચેનો ભાગ).
4. **પાસવર્ડ ભૂલી જાઓ?** login card પર "🔑 સિક્રેટ કોડથી સેટઅપ / પાસવર્ડ બદલવો છે?" ક્લિક → નવો પાસવર્ડ + એકવાર સિક્રેટ કોડ → ફાઈલ આપોઆપ નવા hash થી લખાય.
5. **પાસવર્ડ/email બદલવાના 2 રસ્તા:**
   - **Panel → 🛡️ એક્સેસ કંટ્રોલ** → નવું email/પાસવર્ડ → Save (તરત base64+hash થઈ સેવ).
   - **સીધું GitHub પર** `data/admin.json` edit કરો:
     ```json
     { "v": 2, "email": "<base64(email)>", "pass": "<sha256(password)>", "updated": "2026-11-13" }
     ```
     અથવા સરળતા માટે `"pass": "મારો નવો પાસવર્ડ"` (plain) લખો — site hash તરીકે ઓળખી શકે અને plain હોય તો પણ login ચાલે; પછી પહેલી login વખતે આપોઆપ hash થઈ જાય. જૂનું `"passHash"` field પણ ચાલે (back-compatible).
6. 🔓 **Login પછી** upload/post/settings ચાલે (ફક્ત એ જ ટેબની memory માં કોડ રહે).
7. **🎬 YouTube — ફક્ત લિંક:** Panel → 🎬 માં `https://youtu.be/xxxx` (watch / shorts / live / embed / youtu.be / ફક્ત ૧૧-અક્ષર id — બધું ચાલે) પેસ્ટ કરો એટલે
   **શીર્ષક + થંબનેલ આપોઆપ** આવે (YouTube oEmbed) → ધોરણ/વિષય પસંદ કરી **Save**. ✍️ સંપાદકમાં લિંક મૂકો એટલે ત્યાં પણ થંબનેલ+શીર્ષક પ્રીવ્યુ દેખાય.
   સાઈટ પર દરેક YouTube આઇટમમાં **થંબનેલ + શીર્ષક + ચૅનલ + 👁 ગણતરી** દેખાય અને પોસ્ટર પર ક્લિક કરતાં
   **વિડિયો અમારા જ પેજમાં ચાલે** (`youtube-nocookie` embed, playsinline; ડાઉનલોડ/બહાર જવું નહીં). ના ચાલે તો નીચે **↻ બીજો સર્વર** બટન
   આપોઆપ `youtube.com/embed` પર ખસેડે (4s માં iframe લોડ ન થાય તો એ જાતે પ્રયત્ન કરે).
8. **🗂️ આઇટમ મેનેજર:** Panel → 🗂️ માં દરેક પોસ્ટ/પાઠ/વિડિયો શોધી **✏️ સુધારો** કે **🗑 કાઢી નાખો**
   (કાઢી નાખવાથી `data/catalog.json` માંથી જતું રહે અને સાઈટ તરત અપડેટ થાય). ફાઈલ ડિસ્ક પરથી કાઢી નાખવી હોય તો 📁 File Manager.
   એ જ ટૉબમાં **👁 મોસ્ટ વ્યૂડ પોસ્ટ** બૉક્સ: દરેક પોસ્ટ/વિડિયો ખુલે એટલે ગણતરી (એ બ્રાઉઝરમાં) થાય — બધા વિઝિટર માટે જોઈએ તો
   **⬆️ data/views.json માં સેવ કરો** (હોમ પેજનું “👁 મોસ્ટ વ્યૂડ પોસ્ટ” એ જ ફાઈલ વાપરે છે).
9. **🏷️ શ્રેણી/ધોરણ/ક્વિઝ કેટેગરી:** નવી key+label+icon ભરી **ઉમેરો**; પહેલેથી હોય એવી key/label આપશો તો
   **“આ પહેલેથી જ ઉમેરાયેલું છે”** સંદેશ દેખાય (ડુપ્લિકેટ સેવ થતું નથી). કાઢી નાખતી વખતે એ શ્રેણી/ધોરણ કોઈ આઇટમમાં વપરાતું હોય તો
   સાવચેતી સંદેશ આવે (ડેટા તૂટે એવું થતું નથી). બધું `data/site-config.json → taxonomy` માં સેવ થાય.
10. **🔀 કેટેગરી પછી શું પૂછાય (mode) + 🧩 સબ-કેટેગરી:** Panel → 🧠 નીચે “કેટેગરી સેટિંગ” માં દરેક મુખ્ય કેટેગરી માટે એક dropdown —
    - **ધોરણ + વિષય (૭ વિષય)** → ફક્ત `🎓 ધોરણ મુજબ` કેટેગરી માટે (વિદ્યાર્થી પહેલા ધોરણ, પછી વિષય પસંદ કરે).
    - **સબ-કેટેગરી મુજબ** → GK / તર્કશક્તિ / સમકાલીન / TAT / HTAT / CET જેવા બધા મુખ્ય કેટેગરી માટે (**ધોરણનો સ્ટેપ દેખાતો નથી**).
    - **સીધા પ્રશ્નો** → કોઈ સ્ટેપ નહીં, બધા પ્રશ્નો મિશ્ર.
    Panel → 🏷️ નીચે **🧩 સબ-કેટેગરી** બૉક્સમાં દરેક કેટેગરીની સબ-કેટેગરી ઉમેરાય (`key` + label + icon) અને **🗑** થી કાઢી નાખવામાં આવે —
    કાઢો એટલે એ સબ-કેટેગરીના **પ્રશ્નો પણ એકસાથે દૂર** (પૂછીને જ કાય) અને સાઇટ તરત જ અપડેટ. બધું `data/quiz.json → cats[].mode / cats[].subs` માં સેવ થાય.
11. **📥 Excel / CSV થી બધા પ્રશ્નો એક સાથે:** Panel → 🧠 → “📥 Excel / CSV થી બધા પ્રશ્નો” માં ફાઈલ પસંદ કરો → **🔍 પૂર્વદર્શન કરો**
    (કઈ પંક્તિ સારી, કઈમાં ખામી — દા.ત. ૪ વિકલ્પ નથી — એ સ્પષ્ટ દેખાય) → **✅ ઉમેરો**.
    - કૉલમ: `cat · sub · grade · subject · diff · પ્રશ્ન · વિકલ્પ A..D · સાચો · સમજૂતી · marks` (English header પણ ચાલે).
      `sub` = સબ-કેટેગરી (GK/TAT જેવા મુખ્ય કેટેગરી માટે); નવી સબ-કેટેગરીનું નામ લખો તો એ પણ યાદીમાં આપોઆપ ઉમેરાય.
    - **સાચો જવાબ** A/B/C/D, 1–4, કે વિકલ્પનું નામ — બધું ચાલે (ગુજરાતી અંક ૧–૪ પણ).
    - એક જ કૉલમમાં ૪ વિકલ્પ જોઈએ તો `વિકલ્પો` કૉલમમાં `A | B | C | D` લખો.
    - ત્રણેય ભાષા માટે અલગ કૉલમ આપી શકો: `પ્રશ્ન (ગુજરાતી)`, `Question (en)`… ન આપો તો એ જ લખાણ ત્રણેય ભાષામાં મૂકાય;
      “🌐 પંક્તિઓનો અનુવાદ કરો” tick કરો તો ઓનલાઇન અનુવાદ થાય (જરા ધીમું).
    - નવી કેટેગરીનું નામ Excel માં લખો તો એ કેટેગરી આપોઆપ યાદીમાં ઉમેરાય.
    - “📋 નમૂનો કોપી કરો” બટનથી હેડિંગની પહેલી પંક્તિ કૉપી થાય. (.xlsx માટે SheetJS વાપરાય છે — `assets/vendor/xlsx.mini.js`, બ્રાઉઝરમાં જ parse થાય, ક્યાંય અપલોડ નહીં.)
12. **🧠 ક્વિઝ મેનેજર (કેટેગરી + સબ-કેટેગરી જ નિર્ણય લે):** **કેટેગરી** dropdown પસંદ કરો એટલે બાજુનાં field બદલાય —
    `ધોરણ મુજબ` માં **ધોરણ + વિષય (૭)** દેખાય, બીજા મુખ્ય કેટેગરીમાં **સબ-કેટેગરી** dropdown દેખાય (ધોરણ/વિષય છુપાય).
    પ્રશ્ન + **૪ વિકલ્પ** + સાચો વિકલ્પ (A/B/C/D radio) → **🌐** થી ત્રણ ભાષા આપોઆપ → **➕ પ્રશ્ન ઉમેરો** — પ્રશ્ન
    `cat` + (`subject`/`grade`) કે (`sub`) સાથે એ જ કેટેગરી-સબ-કેટેગરીમાં સેવ થાય (બધા પ્રશ્નો એક જ ડિબામાં જમા થતા નથી).
    નીચેની યાદી પણ કેટેગરી + સબ-કેટેગરી (અને ધોરણ/વિષય) પ્રમાણે જ ફિલ્ટર થાય. પાસ માર્ક (%) અને પ્રશ્ન દીઠ સમય અહીંથી બદલાય (`data/quiz.json`).

### 🔒 Admin login ની વધુ સુરક્ષા
- login card **email prefill કરતું નથી** અને **browser autofill/password-manager band** છે (`autocomplete="off"` + focus સુધી `readonly`) → public computer પર ક્લિક કરો તો પણ વિગતો આપોઆપ ન ભરાય.
- "Fine-grained PAT", `github_pat_...` જેવા કોઈ શબ્દ/placeholder વિઝિટરને દેખાતા નથી — ફક્ત "સિક્રેટ કોડ".
- 🛡️ **ભાષા/ટેક્સ્ટ સુરક્ષા (round-trip fix):** GitHub પરથી ફાઈલ વાંચતી વખતે UTF-8 સાવધાનીથી decode થાય (અગાઉ Gujarati text "mojibake" થઈ જતો — હવે `getFile` માં TextDecoder + જૂની corrupt data માં auto-repair).

| ફક્ત `@gmail.com` | બીજી ડોમેઈન ⇒ ❌ "ફક્ત આ ઈમેઈલ ડોમેઈન ચાલે: gmail.com" |
| ટપકું પકડો | `haresh@gmail.co` ⇒ ❌ + સૂચના "…@gmail.com તો ઠીક?" (એક ક્લિક માં સુધારો) |
| Gmail નાં નિયમ | ૬–૩૦ અક્ષર, ફક્ત a–z 0–9 `.` `_`, શરૂ/અંતે બિંદુ નહીં, `..` નહીં |
| મોબાઈલ નંબર | ૧૦ અંક, ૬–૯ થી શરૂ, `+91`/`0` આપોઆપ સાફ, બીજા દેશ નો નંબર રોકાય |
| ખોટા/બનાવટી નંબર | `1234567890`, `9876543210`, એ જ અંક વારંવાર, ૬ અંક ની સીડી ⇒ ❌ રોકાય |
| ✅ ઈમેઈલ **ખરેખર ચાલુ** હોય | Admin ⇒ 🔐 માં **Google Client ID** ભરો ⇒ ફોર્મ પર "🔐 Google વડે ચકાસો". sign-in કરેલી Gmail જ સ્વીકારાય ⇒ ખોટું કે બંધ પડેલું ઈમેઈલ ચાલે જ નહીં (કોઈ સર્વર નહીં). "ફરજિયાત" ચેક કરો ⇒ વગર ચકાસણી રજિસ્ટ્રેશન થશે નહીં |
| 🔢 OTP (વૈકલ્પિક) | `auth.otpEndpoint` માં webhook ભરો ⇒ વપરાશકર્તા પોતાના નંબર પર આવેલો કોડ ભરે એટલે જ ખાતું બને |

> 💡 "નંબર ખરેખર ચાલુ છે?" એ બ્રાઉઝર માંથી ૧૦૦% તપાસી શકાતું નથી (એટલે format + નકલા-નંબર ના નિયમ + OTP hook). Admin ને દરેક નોંધ પર **⏳ ચકાસણી બાકી / ✅ ચકાસાયેલ** દેખાય છે.

### ૨) Admin → 👥 ખાતાં: નામ · મોબાઈલ · ઈમેઈલ ની યાદી + 🚫 બ્લોક / ✅ અનબ્લોક
- **📋 રજિસ્ટ્રેશન ની યાદી** — દરેક નોંધ: નામ, મોબાઈલ (wa.me લિંક સાથે), ઈમેઈલ, ભૂમિકા, તારીખ, હાલત + ક્રિયાઓ. ઉપર શોધ (નામ/મોબાઈલ/ઈમેઈલ) અને 📋 CSV નિકાસ.
- **🚫 બ્લોક** ⇒ કારણ પૂછાય → એ ખાતું login કરી શકે નહીં, એને સંદેશ દેખાય:
  *"⛔ તમારું ખાતું બંધ કરવામાં આવ્યું છે · કારણ: … · <સંપર્ક email>"*. ચાલુ સેશન હોય તો એ પણ તરત બંધ.
- **✅ અનબ્લોક** ⇒ એ જ ખાતું ફરી login થઈ શકે. બ્લોક `data/users.json` માં (`users[].blocked` + `blockedEmails`) સેવ થાય ⇒ **બધા ઉપકરણ પર** લાગુ પડે.
- બાકી ની ક્રિયાઓ: 🔑 પાસવર્ડ રીસેટ · 🗑 ખાતું કાઢો · ➕ નવું ખાતું (મોબાઈલ સાથે) · ➕ નોંધ થી ખાતું ખોલો · "બધાં નું ખાતું બનાવો".
- **💾 repo માં સેવ કરો** ⇒ ઉપકરણ ની નોંધ `data/registrations.json` માં જાય (બધી Admin જગ્યા એ જ યાદી જુએ).
- બીજા ઉપકરણ પર ની રજિસ્ટ્રેશન આપોઆપ repo માં આવી શકે નહીં (visitor પાસે GitHub token હોતો નથી) — એટલે `auth.webhook` ભરો ⇒ નોંધ તરત Google Sheet માં જાય, અને Admin ⇒ **⬇️ Sheet માંથી લાવો** એક ક્લિક માં બધી નોંધ.
- ⚠️ repo public હોય તો આ ફાઈલ કોઈ પણ વાંચી શકે. `robots.txt` માં `/data/users.json`, `/data/registrations.json`, `/data/notice.json` Disallow કરેલાં છે (search માં ન જાય), પણ નંબર ખાનગી રાખવા હોય તો **webhook/Sheet** વાપરો.

### ૩) 📰 બ્રેકિંગ ન્યૂઝ પટ્ટી (Admin → 📣)
- **હેડર ની ઉપર**, પાનાં ના સાદા પ્રવાહ (flow) માં લાલ-નારંગી પટ્ટી — `position:relative`, sticky/fixed નહીં ⇒ પટ્ટી સ્ક્રિન પર કંઈ ઢંકાતી નથી, અને પાનું સરકાવો તો એ પણ સાથે સરકે. `body.has-news` નું `--header-h` override કાઢી હાબ ⇒ સાઇડબાર/ટૉબ્સ નો ઉપરનો ફાટો ઠીક રહે.
- ડાબે નું chip હંમેશાં **🔴 Breaking News** (`news.label` — Admin માંથી ૩ ભાષા માં બદલાય, default એ જ).
- **વપરાશકર્તા એ પટ્ટી કાઢી શકે નહીં:** `news.dismissible` default `false` ⇒ ✕ બટન જ બને નહીં, અને પહેલાં કોઈએ કાઢેલી હોય (`localStorage oeg.news.off`) તોય એ નોંધ આપોઆપ સાફ થઈ જાય. પટ્ટી હટાવવાનો એક જ રસ્તો: Admin → 📣 ⇒ 📰 પટ્ટી બંધ.
- માઉસ ફેરવો ⇒ અટકે (`news.pauseOnHover`); ફોન પર પણ ચાલે (`prefers-reduced-motion` હોય તો ticker બંધ, સાદી યાદી).
- Admin → 📣: પટ્ટી ચાલુ/બંધ, નામ (૩ ભાષા; default **Breaking News**), ઝડપ (અક્ષર/સેકન્ડ), પોતાની લીટીઓ (`લખાણ | લિંક` દર લીટીએ), અને **"નવી પોસ્ટ નું ટાઈટલ આપોઆપ જોડો"** (કયા પ્રકાર, કેટલા દિવસ, કેટલી લીટી). સેવ કરતી વખતે `dismissible:false` જ લખાય ⇒ ✕ પાછું ન આવે.
- ⇒ **✍️ નવી પોસ્ટ પ્રકાશિત કરો એટલે એનું ટાઈટલ તરત પટ્ટી માં** (ક્લિક ⇒ એ જ પોસ્ટ `#/view/<id>`).

### ૪) 🔔 સૂચના — ફોન / લેપટોપ પર
- હેડર ની **ઘંટડી** ⇒ "ચાલુ કરો" ⇒ બ્રાઉઝર permission ⇒ પછી સિસ્ટમ નોટિફિકેશન (icon + લિંક; ટૅપ કરો ⇒ એ જ પાનું).
- ક્યારે સૂચના: (a) **નવી પોસ્ટ** પ્રકાશિત થાય, (b) **Admin ની નોટિસ** — Admin → 📣 → ટાઈટલ/લખાણ/લિંક ભરી "📣 સૌને મોકલો" ⇒ `data/notice.json` (છેલ્લી ૧૨ યાદ રહે, કાઢી પણ શકાય).
- તપાસ: સાઇટ ખુલ્લી હોય ત્યારે દર `pollMinutes` મિનિટે + પાનું બદલો એટલે તરત. (બ્લોગર થીમ પર ફાઈલ CDN કૅશ માંથી વાંચાય — `?ts=` લગાવેલું હોય એટલે નવી નોટિસ થોડી મિનિટ માં જ દેખાય.) GitHub Pages પર `sw.js` (service worker) નોંધાય ⇒ Android/Chrome પર પણ; Blogger થીમ પર SW બીજા origin માં નોંધાઈ શકે નહીં ⇒ એ જ સૂચના page-level Notification થી મળે.
- ⚠️ બ્રાઉઝર **બંધ** હોય ત્યારે પણ પહોંચાડવાનું હોય તો push service (OneSignal / FCM + VAPID) જોડવું પડે — `sw.js` માં `push` listener તૈયાર મૂક્યો છે, એમાં push service ની કી/config જોડવાનું બાકી.

### ૫) 🟢 નવી પોસ્ટ ⇒ વૉટ્સએપ મેસેજ (ટૂંકી વિગત + લિંક)
- Admin → 📣 → 🟢: નંબર (દેશ કોડ સાથે — શાળા/ગ્રુપ નો નંબર), મેસેજ ફોર્મટ, "કોણને દેખાય" (Admin ▸ બધા ▸ ના).
- દરેક નવી પોસ્ટ માટે મેસેજ આપોઆપ બને — `{icon} {title}`, ટૂંકી વિગત, લિંક ⇒ **વૉટ્સએપ પર મોકલો** (contact પસંદ કરી send) અથવા **બધી એક સાથે મોકલો**.
- **પાનાં પર કંઈ તરતું બોક્સ નહીં:** એક વાર નીચે જમણે "નવી પોસ્ટ — વૉટ્સએપ પર મોકલો" નું બોક્સ દેખાતું (screen નડતું) — એ કાઢી હાબ. `OEG.notify.clearChip()` ફક્ત જૂના cache માં બચેલું બોક્સ હટાવે; યાદી + બટન હવે **ફકત Admin → 📣 → 🟢** પૅનલ માં જ.
- 🟢 પૅનલ નું **📤 અહીં થી કોણ મોકલી શકે**: 🛠️ Admin ⇒ એક-એક પોસ્ટ નો 🟢 બટન · 👥 બધા ⇒ સાથે માં **📤 બધી એક સાથે મોકલો** · 🚫 બંધ ⇒ યાદી દેખાએ પણ મોકલવાનું બટન નહીં.
- Admin login હોય ત્યારે સાઇટ પર જમણીએ નાનો પટ દેખાય (નવી પોસ્ટ ની યાદી + બટન). મોકલી દો ⇒ "મોકલ્યું" નોંધાય ⇒ બીજી વાર દેખાતું નહીં ("ફરીથી બધી બતાવો" થી પાછી યાદી).
- ⚠️ બ્રાઉઝર માંથી **ટૅપ વગર** send કરવું WhatsApp ની નીતિ પ્રમાણે શક્ય નથી — એટલે "એક ક્લિક". સંપૂર્ણ આપોઆપ મોકલવા **WhatsApp Cloud API + webhook** જોડો.

#### વૈકલ્પિક: Google Apps Script (Sheet માં નોંધ + OTP) — ૫ મિનિત કામ
`script.google.com` ⇒ નવી Project ⇒ નીચે નો કોડ ⇒ Deploy ⇒ Web app (Execute as: Me, Access: Anyone) ⇒ એ `/exec` લિંક Admin → 👥 → 🔐 માં **webhook** ભાગે ભરો.

```js
const SHEET = "reg";                                   // Sheet નું નામ
function doPost(e) {                                    // રજિસ્ટ્રેશન નોંધ
  const o = JSON.parse(e.postData.contents || "{}");
  const sh = SpreadsheetApp.getActive().getSheetByName(SHEET) || SpreadsheetApp.getActive().insertSheet(SHEET);
  sh.appendRow([new Date(), o.name, o.email, o.phone, o.role, o.grade, o.subject, o.verified || ""]);
  return ContentService.createTextOutput(JSON.stringify({ ok: true }));
}
function doGet(e) {                                     // Admin ⇒ ⬇️ Sheet માંથી લાવો
  if ((e.parameter.action || "") !== "list") return ContentService.createTextOutput(JSON.stringify({ ok: false }));
  const sh = SpreadsheetApp.getActive().getSheetByName(SHEET);
  const items = sh.getDataRange().getValues().slice(1).map(r =>
    ({ at: String(r[0]).slice(0, 10), name: r[1], email: String(r[2] || "").toLowerCase(), phone: String(r[3] || "").replace(/\D/g, "").slice(-10), role: r[4] }));
  return ContentService.createTextOutput(JSON.stringify({ items })).setMimeType(ContentService.MimeType.JSON);
}
```

- ઈચ્છો તો Firebase પણ ચાલુ રહે છે: `site-config.json` → `firebase.apiKey` ભરો એટલે register/login Firebase Identity Toolkit થી ચાલે.

## 📱 સિક્રેટ કોડ (GitHub PAT) ક્યાં સેવ છે?

**કોઈ પણ GitHub ફાઈલમાં નહીં** — repo, `data/*.json`, commit history કે source કોડમાં એ કોડ લખાતો નથી (એટલે કોઈ શોધી શકે નહીં).

- પહેલી વાર તમે Panel → 🔗 Connect માં (અથવા login card માં) કોડ ભરો અને **"આ કોડ ફક્ત આ બ્રાઉઝરમાં સુરક્ષિત રાખો"** ચેક રાખો (default ચાલુ) → કોડ **AES-256-GCM** થી એન્ક્રિપ્ટ થઈ તમારા બ્રાઉઝરના `localStorage` માં રહે છે.
- એન્ક્રિપ્શન key એ જ બ્રાઉઝરમાં છુપાયેલા અલગ random device-key માંથી બને છે → બીજા ફોન/PC પર એ જ blob ખોલો તો પણ **વાંચી ન શકાય**.
- બ્રાઉઝરની storage ખોલો તો પણ `oeg.v.9f2c` નામના opaque key હેઠળ ગબડતું random text દેખાય (કોડ સીધો દેખાતો નથી).
- Tab બંધ કરો તો પણ **આવતી વખતે email + પાસવર્ડ જ ભરવો** — કોડ આપોઆપ લાગુ થાય, upload/post કામ ચાલુ રહે (page reload દરમિયાન tab-cache કામ કરે છે).
- 🔓 Admin login થયા પછી Panel માં "💾 આ ઉપકરણ પર સેવ ✔" દેખાય; જાહેર/બીજા computer પર હોય તો **"🗑️ ભૂલી જાઓ"** દબાવો (અથવા remember checkbox uncheck કરો).
- logout/lock કરો એટલે tab-cache તરત કાઢી નાખાય.

> ⚠️ Web પર browser storage એટલે ફક્ત *તમારું ઉપકરણ* — એ computer નો બીજો વાપરનાર (અથવા malware) તમારી ખુલ્લી browser session વાપરી શકે. એટલે જાહેર/office PC પર remember બંધ રાખો।

## 💰 AdSense — દરેક પેજ પર જાહેરાત (વધુ આવક માટે)

- Admin Panel → 💰 માં **Publisher ID** (`ca-pub-…`) ભરો → સાઈટ **સ્ક્રિપ્ટ આપોઆપ `<head>` માં નાખે છે** (આપે `index.html` એડિટ કરવું પડે નહીં).
- **સ્લોટ:** `homeTop`, `homeMid`, `listTop`, `listMid`, `gradeTop`, `viewTop`, `viewMid`, `videoTop`, `quizTop`, `quizResult`, `gameTop`, `inFeed`, `contentBottom` + દરેક પાનાનાં તળિયે `footerTop` — **દરેક પેજ પર ક્યાં ને ક્યાં તો જાહેરાત બેસે જ** છે.
- **સાઇઝ એક જ જગ્યાએ:** `💰 AdSense` ની ઉપર **📏 જાહેરાતનો સાઇઝ** પસંદ કરો (`Auto`, `Rectangle`, `Horizontal`, અથવા `300x250`, `728x90` જેવાં ચોક્કસ માપ) → **બધા સ્લોટ એ જ સાઇઝ વાપરે**. નીચે ફક્ત **slot ID** ભરવાનાં — બીજું કંઈ થીજવવું પડતું નથી.
- Slot ID ખાલી હોય અને Publisher ID ભરેલું હોય તો **auto-format** વાપરાય — એટલે જગ્યા ખાલી રાખવી પડતી નથી. સાઇઝ પસંદ કર્યો હોય તો દરેક સ્લોટ એ જ માપે ખૂલે.
- Publisher ID ખાલી હોય તો ખાલી ડબ્બો **વિઝિટરને દેખાતો નથી**; ફક્ત localhost/Admin માં ગોઠવણ દેખાય.
- મહત્તમ આવક માટે સૂચન: **homeTop + listMid + inFeed + viewMid + quizResult** (મોબાઇલ ટ્રાફિક અહીં વધુ), AMP નહીં, ad density ઓછું રાખો.
- ⚠️ **ઇમાનદારીની નોંધ:** મંજૂરી/આવકની ગેરંટી કોઈ આપી શકે નહીં — એ Google નો નિર્ણય છે. અમે તરફ સાઈટ **પોલિસી-સેફ** રાખી છે: “જાહેરાત” લેબલ, ડાઉનલોડ/પ્લે બટનથી દૂર, પોપ-અપ/ઇન્ટર્સ્ટિશિયલ નહીં, સાચો `robots.txt`, ગોપનીયતા માટે contact email. Panel માં 💰 નીચે પગલાંની યાદી છે.

## 🔎 SEO — Google માં ઉપર લાવવા

- દરેક રૂટ પર **title, description, canonical, Open Graph, Twitter card, JSON-LD** (WebSite / Organization / VideoObject / LearningResource / Quiz / ItemList / Breadcrumb) આપોઆપ લાગે છે — `js/meta.js`.
- **કેનોનિકલ + શેર લિંક હંમેશા અત્યારના host પ્રમાણે:** GitHub પરથી ⇒ `…github.io/OEG/#/view/<id>`, Blogger iframe માંથી ⇒ **તમારું `…blogspot.com/#/view/<id>`** (`?shareBase=` અથવા referrer થી). ક્યાંય `github.io` hard-code કરેલું નથી.
- **સ્ટેટિક (crawlable) પાનાં** — JS વગર પણ Google વાંચી શકે:
  - `p/<item-id>.html` — દરેક પાઠ/પોસ્ટ/વિડિયો (ત્રણેય ભાષામાં શીર્ષક+વર્ણન, વિડિયો હોય તો embed + થંબનેલ)
  - `g/<ધોરણ>.html` — ધોરણ પાનું (બધાં પ્રકાર + ૭ વિષય) · `g/all.html`
  - `q/<કેટેગરી>.html` — ક્વિઝ કેટેગરી પાનું · `q/all.html`
  - બનાવવા: `npm run seo` (અથવા `node scripts/seo.mjs`) પછી commit — `sitemap.xml` + `robots.txt` પણ અપડેટ.
- Admin → 🔎 SEO માં સાઈટનું શીર્ષક/વર્ણન/કીવર્ડ + `site verification` ભરો → save કરો એટલે `data/site-config.json` સાથે **sitemap.xml + robots.txt** પણ લખાય છે.
- બીજું કરવા જેવું (તમારું કામ): Search Console માં property add → sitemap submit → Blogger પોસ્ટમાં અહીંની લિંક આપો (backlink) → નવું મટિરિયલ નિયમિત મૂકો. **નવી સાઈટને ટોપ પર આવવા ૨–૮ અઠવાડિયાં લાગી શકે.**

## 🏷️ કેટેગરી ઉમેરો → તરત જ ક્વિઝમાં

`🏷️ કેટેગરી` માં નવી **ક્વિઝ કેટેગરી** ઉમેરો એટલે જ તે પંક્તિમાં દેખાય: `🧠 પ્રશ્નો` નો **કેટેગરી dropdown**, પ્રશ્નોની યાદી, કેટેગરી-ફ્લેગ્સ (ધોરણ/વિષય ચાલુ-બંધ) અને `🏅 પ્રમાણપત્ર` નો વિષય picker — બધામાં તરત.

- કેટેગરી **કાઢી નાખો** તો તેમાંના પ્રશ્નો + ફ્લેગ પણ એકસાથે દૂર (પૂછે છે: “બધા પ્રશ્નો પણ કાયમ માટે દૂર થશે”).
- 🌳 **ત્રણ સ્તરનું વૃક્ષ** (`🏷️ કેટેગરી` ટૉબ): **કેટેગરી ▸ ઉપ-શ્રેણી (વિષય/સબ-કેટેગરી) ▸ ચેપ્ટર (નંબર + નામ)**. `➕ ઉમેરો` બટન દરેક સ્તરે છે (નવી કેટેગરી / નવો વિષય / નવું ચેપ્ટર), અને **રદ કરો ફક્ત નીચે તરફ** લાગુ પડે: કેટેગરી રદ → એની ઉપ-શ્રેણી + ચેપ્ટર + પ્રશ્નો; ઉપ-શ્રેણી રદ → એના ચેપ્ટર + પ્રશ્નો; ચેપ્ટર રદ → ફક્ત એ ચેપ્ટર. ઉપરનું સ્તર ક્યારેય નુકસાન પામતું નથી.
- ચેપ્ટરમાં **નંબર** (ગુજરાતી અંકો ચાલે: ૧ → key `ch1`) + **નામ** + વૈકલ્પિક **ધોરણ** (ખાલી = બધાં ધોરણ); ✏️ થી નામ/નંબર/ધોરણ સુધારી શકાય.
- એ જ નામથી ફરી ઉમેરવાનો પ્રયાસ → ⚠️ “પહેલેથી છે” સંદેશો (ડુપ્લિકેટ બનતું નથી).
- **કોઈ “કી” ફીલ્ડ હવે નથી** — નામ ભરો, key આપોઆપ બને છે (ગુજરાતી અંક ૧૨ → `12`). **ક્રમ બદલવા ⬆⬇ બટન** વાપરો (દરેક યાદીમાં: કેટેગરી, ધોરણ, વિષય, ક્વિઝ સબ-કેટેગરી, ચેપ્ટર, પ્રેક્ષક અને એમની બાબતો).
- યાદીની પંક્તિમાં **નામ તરત જ બદલાય** (input માં લખીને બહાર ક્લિક કરો) — અલગ એડિટ ફોર્મ નહીં.

## 🎯 પ્રેક્ષક: વિદ્યાર્થી ▸ શિક્ષક ▸ આચાર્ય ▸ ઓફિસ

- **Upload · ✍️ એડિટર · 🎬 વિડિયો** — ત્રણેય ફોર્મમાં પહેલું પસંદગી **પ્રેક્ષક** ની. `વિદ્યાર્થી` પસંદ કરો એટલે **ધોરણ** ખુલે અને ધોરણ પસંદ કરો એટલે **વિષય**; `શિક્ષક / આચાર્ય / ઓફિસ` પસંદ કરો એટલે ધોરણ-વિષય ને બદલે **એ પ્રેક્ષકની બાબતો** (બાબત ▸ ઉપ-બાબત — ૩ સ્તર) દેખાય.
- દરેક dropdown પાસે **➕ (નવું ઉમેરો)** અને **🗑 (કાઢી નાખો)** — એ જ પ્રેક્ષકની યાદીમાં ઉમેરો/કાઢો. વધુ નિયંત્રણ (નામ બદલો, ⬆⬇ ક્રમ) `🏷️ કેટેગરી` ટૉબ નીચેના **🎯 પ્રેક્ષક** બ્લોક માંથી.
- **શું દેખાય:** login કરેલા વપરાશકર્તા ને ફક્ત એમના પ્રેક્ષક પ્રમાણે — વિદ્યાર્થી ને પાઠ્યપુસ્તક/સ્વાધ્યાયપોથી/ક્વિઝ/રમત/વિડિયો, શિક્ષક ને શિક્ષકની બાબતો, આચાર્ય ને આચાર્ય+ઓફિસ ની બાબતો. મેનુ, પાનાંની યાદી, શોધ અને હોમ પેજ — બધું એ જ નિયમ મુજબ છંટાય. વિદ્યાર્થી ને ધોરણ-વિષય ન પૂછવાનું (Admin → 👥 વપરાશકર્તા માં પણ આચાર્ય પસંદ કરો એટલે ધોરણ-વિષય છુપાય).
- **પ્રેક્ષક નાં પાનાં (hub):** `#/student` · `#/teacher` · `#/principal` · `#/office` — દરેક પર પ્રકાર પ્રમાણે ટૅબ (બધાં + જે પ્રકાર ની સામગ્રી છે એ જ), નીચે બાબત ▸ ઉપ-બાબત ની ચિપ્સ, અને જાહેરાત ની જગ્યા (listTop · listMid · contentBottom · footerTop). ઊંડા લિંક પણ ચાલે: `#/principal?audSub=order&audSub2=order-circular`, `#/office?cat=circular`. `data/site-config.json` માં audience ને `route` આપો તો URL બદલાય (ના ભર્યું તો key જ route).
- જે પ્રેક્ષક કોઈ type સાથે જોડાયેલું નથી (જેમં આચાર્ય) એ ટોચ નાં મેનુ માં આપોઆપ જોડાય; type નાં પાનાં (`#/teachers`, `#/textbooks`, `#/office?cat=office`…) એવાં તેવાં રહે છે — એટલે જુ નાં લિંક/SEO ને ફટકો પડતો નથી.
- **નોંધ:** login ન હોય (મહેમાન) કે Admin ખુલ્લું હોય ત્યારે **બધું દેખાય** — કોઈ સામગ્રી છુપાતી નથી.
